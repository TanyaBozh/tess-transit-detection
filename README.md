# TESS Transit Detection

## Цель проекта

Разработка нейронной сети для обнаружения транзитоподобных сигналов в кривых блеска переменных звёзд, наблюдавшихся миссией TESS.

## Планируемый pipeline

1. Получение данных TESS для звёзд каталога.
2. Предварительная обработка кривых блеска.
3. Выделение известных переменных звёзд с транзитоподобными и без транзитоподобных сигналов.
4. Добавление искусственных транзитов в подходящие кривые без транзитных сигналов.
5. Подготовка обучающей выборки.
6. Обучение и оценка нейронной сети.

На текущем этапе основное внимание уделяется освоению `eleanor`, проверке воспроизводимого окружения и разбору существующего кода.
